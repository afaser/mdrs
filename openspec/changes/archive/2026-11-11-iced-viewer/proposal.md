## Why

Нужен нативный просмотрщик markdown с запуском заметно быстрее вебвью-стека. Tauri/WebKit стартует сотни миллисекунд и тянет HTML/CSS; egui быстрый, но не даёт встроенного markdown и нормальной типографики. Iced 0.14 — чистый Rust, GPU-рендер через wgpu и встроенный markdown-виджет с `Viewer` trait, который закрывает будущие tree-sitter и диаграммы без форков.

## What Changes

- Новый бинарь `mdrs` на iced 0.14: GPU-рендер через wgpu (Vulkan), `tiny-skia` отключён.
- Открытие документа тремя путями: аргумент командной строки, диалог через XDG-portal (`rfd`), drag&drop в окно.
- Рендер GFM: заголовки, списки, цитаты, таблицы, блоки кода с подсветкой, картинки, ссылки; текст выделяется и копируется.
- Тема Catppuccin Mocha с зелёным акцентом; шрифт JetBrainsMono Nerd Font встраивается в бинарь.
- Live reload по изменению файла с сохранением позиции прокрутки.
- Приёмка запуска: тёплый старт до первого кадра не более 150 мс; wgpu обязан выбрать RADV, а не llvmpipe.
- **BREAKING**: заглушка `src/main.rs` с `println!` удаляется; проект перестаёт быть «только std» — это осознанное изменение стека.
- Отложено до отдельных изменений: подсветка через tree-sitter, mermaid/UML, TOC, поиск по документу, вкладки.

## Capabilities

### New Capabilities

- `markdown-viewer`: открытие, рендер и live reload markdown-документа, тема и шрифт, требования к времени запуска.

### Modified Capabilities

Нет.

## Impact

- `Cargo.toml`: `iced` 0.14 (`default-features = false`), `rfd`, `notify`, `two-face`/`syntect`; фичи `wgpu`, `markdown`, `highlighter`, `image`, `svg`.
- Новые подсистемы: `app`, `document`, `markdown`, `theme`, `viewer`, `watch`, `open`; `main.rs` остаётся точкой входа без логики.
- Системные зависимости: Vulkan loader и RADV (наличие проверено), Wayland/X11, Mesa; WebKit/GTK больше не нужны.
- `AGENTS.md`: правило «Rust, только стандартная библиотека» несовместимо с iced; переформулировка правила — отдельное решение, в это изменение не входит.
- Холодный первый запуск после обновления драйвера (~1.2 с из-за Mesa shader cache) приложением не контролируется; тёплый старт — предмет приёмки.
