## Purpose

Просмотрщик открывает markdown-документ с диска и показывает его в нативном окне с темой Catppuccin Mocha (зелёный акцент), встроенным шрифтом JetBrains Mono Nerd Font и обновлением при изменении файла без потери позиции чтения.

## ADDED Requirements

### Requirement: Открытие документа

Просмотрщик ДОЛЖЕН (MUST) открывать markdown-файл аргументом командной строки и диалогом выбора файла на любой поддерживаемой оконной системе, а перетаскиванием — там, где оконная система доставляет файлы в приложение (X11/XWayland).

#### Scenario: Аргумент командной строки

- **WHEN** процесс запущен как `mdrs path/to/file.md`
- **THEN** окно показывает содержимое этого файла, а заголовок окна содержит имя файла

#### Scenario: Выбор через диалог

- **WHEN** пользователь нажимает Ctrl+O и выбирает файл в системном диалоге
- **THEN** текущий документ заменяется выбранным

#### Scenario: Перетаскивание

- **WHEN** пользователь перетаскивает файл в окно приложения в сессии X11 или XWayland
- **THEN** приложение открывает этот файл

#### Scenario: Перетаскивание на Wayland

- **WHEN** приложение запущено в нативной сессии Wayland и пользователь перетаскивает файл
- **THEN** приложение не падает и не зависает; файл открывается через Ctrl+O или аргумент командной строки

### Requirement: Рендер markdown

Просмотрщик ДОЛЖЕН (MUST) отображать заголовки, абзацы, упорядоченные и неупорядоченные списки, цитаты, горизонтальные линии, таблицы, изображения, ссылки и блоки кода.

#### Scenario: Таблица

- **WHEN** документ содержит GFM-таблицу
- **THEN** она отображается сеткой с заголовком и строками

#### Scenario: Блок кода с языком

- **WHEN** документ содержит блок кода с указанным языком
- **THEN** токены подсвечиваются цветами темы, а не выводятся одним цветом

#### Scenario: Неизвестный язык

- **WHEN** у блока кода указан неизвестный язык
- **THEN** блок отображается моноширинным текстом без подсветки и без ошибки

#### Scenario: Относительное изображение

- **WHEN** документ ссылается на изображение относительным путём
- **THEN** изображение загружается из каталога документа

#### Scenario: Отсутствующее изображение

- **WHEN** файл изображения не найден
- **THEN** показывается alt-текст, приложение не завершается аварийно

### Requirement: Ссылки

Просмотрщик ДОЛЖЕН (MUST) открывать внешние ссылки в системном браузере, не заменяя документ внутри приложения.

#### Scenario: Внешняя ссылка

- **WHEN** пользователь кликает ссылку `https://...`
- **THEN** URL открывается системным браузером, окно просмотрщика продолжает показывать документ

### Requirement: Выделение и копирование

Текст документа ДОЛЖЕН (MUST) выделяться мышью и копироваться в системный буфер.

#### Scenario: Копирование фрагмента

- **WHEN** пользователь выделяет абзац и нажимает Ctrl+C
- **THEN** буфер обмена содержит выделенный текст

### Requirement: Тема

Приложение ДОЛЖНО (MUST) использовать палитру Catppuccin Mocha: фон `#1e1e2e`, основной текст `#cdd6f4`, зелёный акцент `#a6e3a1` для ссылок и заголовков.

#### Scenario: Акцентный цвет

- **WHEN** документ содержит заголовок первого уровня и ссылку
- **THEN** оба отрисованы цветом `#a6e3a1` на фоне `#1e1e2e`

### Requirement: Шрифт

Приложение ДОЛЖНО (MUST) отображать текст шрифтом JetBrains Mono Nerd Font, встроенным в бинарь, и не зависеть от наличия шрифта в системе.

#### Scenario: Машина без установленного шрифта

- **WHEN** приложение запущено на системе, где JetBrains Mono Nerd Font не установлен
- **THEN** документ отрисован этим шрифтом

### Requirement: Live reload

При изменении открытого файла приложение ДОЛЖНО (MUST) обновить содержимое в течение 500 мс, сохранив позицию прокрутки.

#### Scenario: Изменение файла в середине документа

- **WHEN** пользователь прокрутил документ и файл сохранён на диске
- **THEN** содержимое обновилось, а позиция прокрутки осталась прежней

#### Scenario: Файл временно отсутствует

- **WHEN** файл на мгновение исчез при атомарном сохранении
- **THEN** приложение сохраняет последнее содержимое и не показывает ошибку

### Requirement: Ошибки открытия

Приложение ДОЛЖНО (MUST) показывать сообщение об ошибке с путём и не завершаться аварийно, если файл не существует или недоступен для чтения.

#### Scenario: Несуществующий путь

- **WHEN** приложение запущено с путём, которого нет
- **THEN** окно показывает сообщение с этим путём

### Requirement: Время запуска

На референсной машине с тёплым кешем драйвера первый кадр ДОЛЖЕН (MUST) быть показан не позднее 150 мс с момента запуска процесса.

#### Scenario: Тёплый старт

- **WHEN** приложение запущено повторно с тем же документом
- **THEN** время от запуска процесса до первого кадра не превышает 150 мс

### Requirement: Аппаратный рендер

Приложение ДОЛЖНО (MUST) использовать аппаратный GPU-адаптер и не выбирать программный адаптер.

#### Scenario: Выбор адаптера

- **WHEN** приложение стартует на референсной машине с RADV и llvmpipe
- **THEN** используется RADV, программный адаптер не выбран

### Requirement: Без веб-рантайма

Приложение ДОЛЖНО (MUST) работать без JavaScript-движка, браузерного движка и сетевого доступа.

#### Scenario: Машина без Node и браузера

- **WHEN** приложение запущено в системе без Node.js и браузера
- **THEN** документ отрисован полностью
