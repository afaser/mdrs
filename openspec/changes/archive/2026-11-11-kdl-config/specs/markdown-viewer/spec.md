## MODIFIED Requirements

### Requirement: Тема

Приложение ДОЛЖНО (MUST) по умолчанию использовать палитру Catppuccin Mocha Green: фон `#1e1e2e`, основной текст `#cdd6f4`, зелёный акцент `#a6e3a1` для ссылок и заголовков. Палитра, прозрачность фона и цвета ролей ДОЛЖНЫ (MUST) переопределяться KDL-конфигом без пересборки, а при отсутствии конфига ДОЛЖНЫ (MUST) совпадать с перечисленными значениями.

#### Scenario: Акцентный цвет

- **WHEN** конфиг не задаёт палитру, а документ содержит заголовок первого уровня и ссылку
- **THEN** оба отрисованы цветом `#a6e3a1` на фоне `#1e1e2e`

#### Scenario: Акцент переопределён

- **WHEN** конфиг задаёт `theme.palette.accent "#ff0000"`
- **THEN** заголовки и ссылки отрисованы цветом `#ff0000`, а фон остаётся `#1e1e2e`

### Requirement: Шрифт

Приложение ДОЛЖНО (MUST) по умолчанию отображать латиницу шрифтом Source Serif 4, кириллицу — Lora, а код — JetBrains Mono Nerd Font размером 13 с лигатурами. Все дефолтные шрифты ДОЛЖНЫ (MUST) быть встроены в бинарь, чтобы приложение не зависело от установленных системных шрифтов. Гарнитуры, размеры, веса и лица bold/italic ДОЛЖНЫ (MUST) переопределяться конфигом.

#### Scenario: Машина без установленного шрифта

- **WHEN** приложение запущено на системе, где Source Serif 4, Lora и JetBrains Mono Nerd Font не установлены
- **THEN** документ отрисован встроенными шрифтами

#### Scenario: Кириллица в тексте

- **WHEN** документ содержит кириллический текст и конфиг не переопределяет шрифты
- **THEN** кириллица отрисована Lora, а латиница в том же абзаце — Source Serif 4

#### Scenario: Лигатуры кода

- **WHEN** блок кода содержит `->` и конфиг не выключает лигатуры
- **THEN** стрелка отрисована лигатурой

## ADDED Requirements

### Requirement: Код-блок с шапкой

Код-блок ДОЛЖЕН (MUST) отображаться в рамке с шапкой, если шапка включена: слева prompt-символ и язык блока, справа кнопка копирования всего кода. Нажатие кнопки ДОЛЖНО (MUST) помещать в системный буфер исходный код блока без подсветки и без шапки. Видимость шапки, её высота, фон, отступы, цвета, шрифт и размер, prompt-символ, текст для блока без языка и иконка копирования ДОЛЖНЫ (MUST) задаваться конфигом.

#### Scenario: Шапка с языком

- **WHEN** документ содержит блок кода с языком `bash`, а шапка включена
- **THEN** над кодом видны prompt-символ и «Bash», а справа — иконка копирования

#### Scenario: Копирование кода

- **WHEN** пользователь нажимает иконку копирования в шапке
- **THEN** системный буфер содержит весь код блока с сохранёнными пробелами и переводами строк

#### Scenario: Блок без языка

- **WHEN** документ содержит блок кода без указанного языка
- **THEN** в шапке показан настроенный текст-заменитель, а код остаётся подсвеченным как обычный текст

#### Scenario: Шапка выключена

- **WHEN** конфиг задаёт `theme.code-block.header.show #false`
- **THEN** рамка и код видны, шапка и кнопка копирования отсутствуют
