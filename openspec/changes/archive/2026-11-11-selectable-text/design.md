## Context

Смотри `proposal.md`. Текущий `theme::Viewer` рисует markdown через `rich_text`; iced 0.14 не даёт выделения, но ` Paragraph`-трейт предоставляет `hit_test`, `grapheme_position` и `span_bounds`. Виджет `Rich` не публикует свой `Paragraph` и текст строк, поэтому для точного выделения нужен собственный виджет или вендоринг параграфа.

## Goals / Non-Goals

**Goals:**

- Выделение внутри одного markdown-блока с точностью до символа и видимой подсветкой.
- Ctrl+C копирует ровно выделенный текст; клик без протягивания снимает выделение.
- Ссылки продолжают открываться по клику, но выделяются при протягивании.
- Все текстовые элементы markdown, включая блоки кода и ячейки таблиц.

**Non-Goals:**

- Выделение между разными блоками и через прокрутку.
- Клавиатурная навигация выделения, Shift+клик, двойной/тройной клик.
- Копирование HTML/форматирования, сохранение выделения после reload.
- Выделение alt-текста изображений и служебных элементов.

## Decisions

### 1. Новый виджет `selection::SelectableText`

Подсистема `selection` содержит виджет, состояние выделения и геометрию. Виджет принимает готовые spans и `Style`, строит `Renderer::Paragraph`, хранит якорь и фокус выделения как байтовые смещения в тексте блока. `theme::Viewer` создаёт этот виджет вместо `rich_text` для заголовков, абзацев, пунктов списков, цитат, ячеек таблиц и строк кода.

### 2. Геометрия и вендоринг

`Paragraph::buffer()` публичен у конкретного `iced_graphics::text::Paragraph` и отдаёт `cosmic_text::Buffer`: `layout_runs()` содержит текст визуальной строки, `line_top`, `line_height` и глифы с байтовыми смещениями, а `LayoutRun::highlight` считает пиксельный интервал выделения. Вендоринг не нужен: виджет хранит конкретный `Paragraph` рендерера, использует `buffer().hit` для якоря и фокуса и `buffer().layout_runs()` для подсветки. Копирование читает `buffer.lines[*].text()` и сохраняет мягкие переносы без лишних `\n`.

### 3. Подсветка

Подсветка рисуется прямоугольниками через `Renderer::fill_quad` до отрисовки текста. Цвет фона выделения — новый оттенок Catppuccin (`surface1`/`overlay`), цвет текста не меняется. Прямоугольники считаются по визуальным строкам: первая строка от начальной позиции до конца, промежуточные целиком, последняя от начала до конечной позиции.

### 4. Копирование

Виджет не обращается к clipboard напрямую: при завершении выделения он публикует выбранный текст через `Shell::publish`, приложение запоминает его и по глобальному Ctrl+C пишет в clipboard через `iced::clipboard::write`. Глобальный Ctrl+C выбран потому, что обычный текстовый виджет не получает фокус клавиатуры; так копирование работает без отдельного focus-механизма. Клик без выделения не трогает буфер.

### 5. Ссылки и жест

Нажатие запоминает точку и якорь. Протягивание больше порога (3 px) начинает выделение и подавляет клик по ссылке; отпускание без протягивания очищает выделение и передаёт клик в существующий `on_link_click`. Для определения ссылки используется `hit_span` и span-метаданные ссылки. Каждое новое нажатие публикует `Selected(None)` и увеличивает глобальную эпоху выделения; текущий виджет синхронизирует свою эпоху, остальные очищают подсветку. Клик вне текста приходит со статусом `Ignored` и также увеличивает эпоху, поэтому активное выделение снимается.

### 6. Интеграция и стиль

`theme::Viewer` передаёт в виджет те же spans, что и раньше, поэтому подсветка кода, шрифты и цвета сохраняются. Цвет выделения живёт в `theme::palette` и передаётся виджету напрямую: `markdown::Style` — тип iced, его поля не расширяются. Ширина текстовых виджетов остаётся `Shrink`, чтобы не ломать раскладку таблиц; код — один widget с `Wrapping::None` и горизонтальной прокруткой. Кэш подсветки кода остаётся прежним.

## Risks / Trade-offs

- **`Paragraph::buffer()` — API конкретного рендерера** → виджет реализован для `iced::Renderer` (wgpu); при переходе на другой рендерер или iced 0.15 доступ к layout runs нужно проверить заново.
- **Разные размеры шрифта в одном блоке** (inline code, жирный/курсив) → `hit_test` остаётся источником байтовых смещений, а подсветка считается по визуальным строкам; смешанные line height проверяются на фикстуре.
- **Кросс-блочное выделение** не поддерживается; при протягивании за границу блока выделение ограничивается исходным блоком.
- **Производительность** → `Paragraph` кэшируется в состоянии виджета через `compare`/`Difference`; выделение меняет только состояние, не текст.
- **Конфликт со ссылками** → порог протягивания и проверка `hit_span`; клик без движения сохраняет текущее поведение.
- **Clipboard в headless-тестах** → извлечение текста тестируется отдельно, запись в буфер проверяется вручную в X11/Wayland.
