## Why

Спецификация `markdown-viewer` требует выделения текста мышью и копирования по Ctrl+C, но в iced 0.14 у `text`/`rich_text` такого API нет: есть только read-only `text_editor`, который не рендерит markdown-разметку. Изменение `iced-viewer` реализовано без этого требования; нужен отдельный срез с собственным selectable-виджетом.

## What Changes

- Новый виджет selectable-текста для iced 0.14 на основе `Paragraph::hit_test`, `grapheme_position` и `span_bounds`.
- Выделение одним протягиванием мыши внутри одного markdown-блока: заголовка, абзаца, пункта списка, цитаты, ячейки таблицы или блока кода.
- Визуальная подсветка выделения цветом темы и снятие выделения кликом вне текста.
- Ctrl+C копирует выделенный фрагмент в системный буфер; виджет публикует сообщение с текстом, приложение пишет в clipboard.
- Интеграция виджета в `theme::Viewer` вместо `rich_text` для текстовых элементов markdown.
- Выделение между разными блоками (кросс-блочное) не входит в это изменение.
- Правки парсинга markdown, темы, live reload и открытия файлов не требуются.

## Capabilities

### New Capabilities

- `text-selection`: выделение мышью и копирование текста внутри одного markdown-блока.

### Modified Capabilities

Нет.

## Impact

- Новый концепт `selection` (виджет, состояние выделения, hit-testing, отрисовка подсветки) и его подключение в `theme::Viewer`.
- `app::Message` получает сообщение с текстом для clipboard; запись выполняется через `iced::clipboard::write`.
- Новых внешних зависимостей нет: используются `iced::advanced::widget`, `Paragraph` и clipboard-API iced.
- Тесты виджета не требуют окна: hit-testing и нормализация диапазона проверяются на подготовленном `Paragraph`; сценарий Ctrl+C проверяется вручную в X11/Wayland.
