## ADDED Requirements

### Requirement: Прокрутка колесом

Прокрутка колесом ДОЛЖНА (MUST) сдвигать документ не менее чем на восемь строк основного текста за один щелчок независимо от того, доставляет оконная система щелчок дискретной дельтой строк или пиксельной дельтой. Смещение ДОЛЖНО (MUST) происходить плавно: позиция меняется последовательными кадрами за время от 100 до 200 мс, а не одним мгновенным перескоком. Несколько щелчков подряд ДОЛЖНЫ (MUST) складываться без потери движения.

#### Scenario: Дискретный щелчок колеса

- **WHEN** пользователь делает один щелчок колеса, и оконная система сообщает одну дискретную строку
- **THEN** документ сдвигается на восемь строк основного текста

#### Scenario: Пиксельный щелчок колеса

- **WHEN** пользователь делает один щелчок колеса, и оконная система сообщает его пиксельной дельтой
- **THEN** документ сдвигается на восемь строк основного текста, а не на величину пиксельной дельты напрямую

#### Scenario: Плавный ход

- **WHEN** пользователь прокручивает документ колесом
- **THEN** между начальной и конечной позициями видны промежуточные позиции, переход завершается за 100–200 мс, рывка за один кадр нет

#### Scenario: Серия щелчков

- **WHEN** пользователь делает несколько щелчков колеса подряд до завершения предыдущей анимации
- **THEN** итоговое смещение равно сумме шагов всех щелчков, движение не теряется и не откатывается назад

#### Scenario: Границы документа

- **WHEN** документ прокручен до начала или до конца и пользователь крутит колесо в ту же сторону
- **THEN** позиция не выходит за границы содержимого, анимация завершается без бесконечного движения

#### Scenario: Полоса прокрутки и живое обновление

- **WHEN** пользователь перетаскивает ползунок полосы или файл документа обновляется на диске
- **THEN** перетаскивание работает как раньше, позиция после live reload восстанавливается, а незавершённая анимация колеса не мешает новой позиции

#### Scenario: Горизонтальная прокрутка блока кода

- **WHEN** пользователь прокручивает блок кода с широкими строками по горизонтали полосой или при зажатом Shift
- **THEN** блок кода прокручивается по горизонтали, а документ не получает лишнего вертикального смещения
