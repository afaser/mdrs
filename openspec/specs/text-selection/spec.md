# text-selection Specification

## Purpose

Выделение мышью и копирование фрагмента markdown-документа внутри одного текстового блока.

## Requirements

### Requirement: Выделение внутри блока

Текст markdown-блока ДОЛЖЕН (MUST) выделяться протягиванием мыши от точки нажатия до точки отпускания, а выделенный фрагмент — визуально подсвечиваться цветом темы.

#### Scenario: Протягивание мышью

- **WHEN** пользователь нажимает кнопку мыши в абзаце, ведёт курсор и отпускает кнопку
- **THEN** символы между начальной и конечной точками подсвечены, а выделение сохраняется после отпускания

#### Scenario: Направление выделения

- **WHEN** пользователь протягивает мышь справа налево или снизу вверх
- **THEN** выделяется тот же диапазон символов, что и при протягивании в обратном направлении

#### Scenario: Клик без протягивания

- **WHEN** пользователь нажимает и отпускает кнопку мыши в тексте без перемещения
- **THEN** предыдущее выделение снимается

#### Scenario: Границы блока

- **WHEN** пользователь начинает выделение в одном блоке и ведёт курсор в другой блок
- **THEN** выделение ограничено блоком, в котором оно начато

### Requirement: Копирование

Выделенный текст ДОЛЖЕН (MUST) копироваться в системный буфер обмена по Ctrl+C.

#### Scenario: Копирование выделенного фрагмента

- **WHEN** есть активное выделение и пользователь нажимает Ctrl+C
- **THEN** системный буфер содержит ровно выделенный текст

#### Scenario: Копирование без выделения

- **WHEN** активного выделения нет и пользователь нажимает Ctrl+C
- **THEN** содержимое системного буфера не меняется

#### Scenario: Блок кода

- **WHEN** пользователь выделяет строки внутри блока кода и нажимает Ctrl+C
- **THEN** буфер содержит выделенные строки с сохранёнными пробелами и переводами строк

### Requirement: Интеграция с markdown

Выделение ДОЛЖНО (MUST) работать в заголовках, абзацах, пунктах списков, цитатах, ячейках таблиц и блоках кода.

#### Scenario: Все текстовые элементы

- **WHEN** пользователь выделяет текст в заголовке, пункте списка, цитате, ячейке таблицы и блоке кода
- **THEN** каждый элемент показывает подсветку и копирует свой фрагмент

#### Scenario: Ссылка

- **WHEN** пользователь кликает ссылку без протягивания мыши
- **THEN** ссылка открывается как раньше, а не превращается в выделение

#### Scenario: Выделение на ссылке

- **WHEN** пользователь протягивает мышь по тексту ссылки
- **THEN** текст ссылки выделяется, а системный браузер не открывается

### Requirement: Выделение через inline-чип

Выделение мышью ДОЛЖНО (MUST) протягиваться через inline-чип внутри текстового блока: начало, конец и промежуточные точки могут находиться в обычном тексте и в коде. Копирование ДОЛЖНО (MUST) возвращать исходный текст выделенного диапазона, включая пробелы исходного markdown вокруг чипа. Активное выделение ДОЛЖНО (MUST) сохраняться при изменении ширины окна и перестройке переносов, а подсветка — перерисовываться на новых позициях.

#### Scenario: Протягивание через чип

- **WHEN** пользователь начинает выделение в слове перед inline-кодом, ведёт мышь через чип и отпускает в слове после него
- **THEN** выделены оба слова и текст кода, а не только один из фрагментов

#### Scenario: Копирование диапазона с чипом

- **WHEN** выделение пересекает inline-код и пользователь нажимает Ctrl+C
- **THEN** системный буфер содержит исходный текст диапазона с пробелами вокруг кода

#### Scenario: Выделение внутри кода

- **WHEN** пользователь начинает и заканчивает выделение внутри текста inline-кода
- **THEN** копируется ровно выделенная часть кода без соседних слов и без отступов чипа

#### Scenario: Ресайз с активным выделением

- **WHEN** у пользователя есть активное выделение, пересекающее inline-чип, и он изменяет ширину окна
- **THEN** логический диапазон выделения сохраняется, подсветка перерисовывается на новых позициях, а копирование после ресайза возвращает тот же текст

#### Scenario: Граница блока

- **WHEN** выделение начинается в одном текстовом блоке и ведётся в другой
- **THEN** выделение остаётся ограниченным блоком, в котором оно начато, как и до появления чипов
